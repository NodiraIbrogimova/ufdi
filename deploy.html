O‘zbekcha

  1. GitHub hisobini yarating. Domen UFDI bilan boshlanishi uchun mavjud bo‘lsa ufdi-faunadata foydalanuvchi nomini tanlang.
  2. Ochiq repository yarating: FOYDALANUVCHI.github.io. Masalan, ufdi-faunadata.github.io. GitHub uni odatda kichik harflarda beradi.
  3. Barcha fayllarni repository ildiziga joylang. index.html ichki papkada qolmasin.
  4. Settings → Pages → Deploy from a branch → main → / (root) → Save.
  5. Joylashtirish tugagach, Pages ko‘rsatgan havolani oching.

Русский

  1. Создайте аккаунт GitHub. Для адреса, начинающегося с UFDI, выберите доступное имя пользователя, например ufdi-faunadata.
  2. Создайте публичный репозиторий ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io.
  3. Поместите все файлы в корень репозитория.
  4. Settings → Pages → Deploy from a branch → main → / (root) → Save.
  5. Откройте адрес, указанный на странице Pages после публикации.

English

  1. Create a GitHub account. For an address starting with UFDI, choose an available username such as ufdi-faunadata.
  2. Create a public repository named YOUR-USERNAME.github.io.
  3. Put every file at the repository root.
  4. Settings → Pages → Deploy from a branch → main → / (root) → Save.
  5. Open the address shown by Pages when deployment completes.

Local preview: python3 -m http.server 8000 → http://localhost:8000 . Windows: python -m http.server 8000.
